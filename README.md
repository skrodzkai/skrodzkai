# SKRODZKai

**AI systems. Designed and built.**

SKRODZKai designs and builds AI systems: agent orchestration, custom software and automation, applied across five different domains. Most of the engineering is in the harness around the models: how work is scoped and handed off, which tools an agent can reach, how task state is kept, and how results are checked before anyone relies on them.

**[skrodzkai.com](https://skrodzkai.com)**

### Work

**Agentic People OS.** A reference architecture for the People function. Four domains (people analytics, executive compensation, total rewards and retention research) run as coordinated agent workloads on one shared foundation of data, governance and review. Agents assemble recommendations with supporting evidence; people make the decisions. [Read the reference architecture](https://skrodzkai.com/agentic-people-os).

**Prediction markets.** Automated prediction-market trading, from research and probability forecasts to risk checks, order execution and settlement reconciliation, with a traceable record of decisions, orders and outcomes.

**Fantasy football.** Custom rankings and decision models that select draft picks, set weekly lineups and execute roster moves, checking each action against live league state before it is submitted.

**Architecture and spatial modeling.** Residential concept design through plans, 3D models and visual studies, kept consistent as the design is refined.

**Home automation.** Custom software that brings separate home platforms behind one phone-first interface with shared controls and a common view of current state.

---

### Method

- **Custom harnesses.** Each agent works inside a purpose-built harness: a scoped task, the tools it needs, and task state that carries across steps and sessions.
- **Orchestration and integration.** Coordinated agents hand work off through recorded checkpoints and connect to APIs, data sources and local systems through narrow, well-defined interfaces.
- **Automation and validation.** Workflows are built to stop on bad inputs. Tests, acceptance checks and review by a different model family come before release, and consequential decisions go to a person.
